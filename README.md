#  Лунный путь домой

Небольшой браузерный платформер, написанный на ванильном JavaScript с использованием Canvas. Герой — кот, который заблудился на Потерянной планете, должен собрать три луны, не провалиться в лунную лаву, и только когда все условия будут выполнены, откроется портал к нему домой. А ещё здесь есть **секретная концовка** с одиноким призраком :P

## Особенности
-  Плавная физика с гравитацией и коллизиями со всех сторон
-  Анимированная лава с пузырьками и волнами
-  Три собираемые луны и портал на финише
-  Секретная развилка с призраком и диалогом (с выбором!)
-  Сохранение рекорда в `localStorage`
-  Экранные кнопки для мобильных устройств
-  Атмосферная графика на Canvas (без внешних картинок)
-  Два шрифта: **Jura** для интерфейса и рукописный **Caveat** для реплик призрака
-  Корректная пауза при переключении вкладки

## УПРАВЛЕНИЕ

### Клавиатура
| Действие | Клавиши |
|----------|---------|
| Движение влево | `←` или `A` |
| Движение вправо | `→` или `D` |
| Прыжок | `Space`, `↑` или `W` |
| Старт / Продолжить | `Enter` |
| Быстрый рестарт | `R` |
| Выбор варианта в диалоге | `1` или `2` |

### Мобильные устройства
На экранах шириной до 900px автоматически появляются экранные кнопки: `←`, `→` и `↑` (прыжок). Они поддерживают удержание пальца.

## Технологии

- **HTML5** — разметка
- **CSS3** — оформление (переменные, grid, flex, media-queries)
- **Vanilla JavaScript (ES6+)** — без фреймворков и игровых движков
- **Canvas 2D API** — вся графика рисуется кодом
- **ES-модули** (`import` / `export`) — для чистой структуры
- **Google Fonts** — шрифты [Jura](https://fonts.google.com/specimen/Jura) и [Caveat](https://fonts.google.com/specimen/Caveat)
- **localStorage** — сохранение рекорда

### Примеры промптов, которые использовались (большя часть была взята из старого 3-го задания (сейчас на сайте там по-другому как-то...) ):

## Как играть

1. Нажмите **«Старт»** или `Enter`.
2. Прыгайте по платформам, собирите три светящиеся луны.
3. Избегайте лунной лавы внизу экрана — касание означает поражение.
4. Когда все луны собраны, портал в конце уровня откроется.
5. Войдите в портал — и кот вернётся домой!
